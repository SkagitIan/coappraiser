# Preflight product scope

Preflight starts after the appraisal is substantially complete. It accepts a UAD ZIP or separate XML, PDF, images, and optional SSR. It identifies files, records hashes and provenance, runs focused checks, prioritizes findings, supports user decisions, accepts revised versions, and produces a concise workfile record.

Out of scope for this transition: form filling, value recommendations, comp selection, adjustment calculation, UCDP submission, inspection scheduling, mobile capture, and a general chatbot.
