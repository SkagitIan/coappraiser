# Workfile Guardian — Product Walkthrough Script

## Video purpose

Show how CoAppraiser preserves source material, AI actions, generated artifacts, approvals, and verification notes in one assignment workfile.

Suggested length: 90–120 seconds.

## Core promise

Every AI-assisted step becomes a reviewable workfile artifact rather than disappearing as an isolated chat response.

## Screen-by-screen walkthrough

### 1. Create or open an assignment

**Screen:** Dashboard → **New assignment** → enter assignment title, property address, assignment type, and effective date.

**Voiceover:**

“Start with an assignment. This gives every source document, AI action, artifact, and verification item a clear home.”

### 2. Add source material

**Screen:** Assignment detail → **Add source material**. Upload a text file or CSV, or paste source text. Choose a document type.

**Voiceover:**

“Add the material you are actually using: a revision request, report excerpt, engagement letter, market notes, MLS export, or UAD issue text. Original source material stays separate from generated language.”

### 3. Run a workflow

**Screen:** Open Revision Response Agent or another assignment workflow.

**Voiceover:**

“Run a focused workflow from the assignment page. CoAppraiser logs the input, the selected workflow, the model, and the generated result.”

### 4. Review the workfile timeline

**Screen:** Open **Workfile Guardian**.

**Show:** Source documents, saved artifacts, AI action history, and verification checklist.

**Voiceover:**

“The workfile view shows what was provided, what CoAppraiser generated, what was saved, and what remains open for verification.”

### 5. Complete verification and preserve approval

**Screen:** Mark one verification item **Verified**. Show the artifact approval status.

**Voiceover:**

“When you complete a review step, record it in the checklist. Approving an artifact does not erase the original output; it preserves the distinction between generated content and appraiser-reviewed content.”

## Benefits to emphasize

- Cleaner documentation of AI-assisted work
- Easier reconstruction of how a response or memo was developed
- Clear separation between source, draft, edit, and approval
- Less dependence on scattered notes and untracked conversations

## Suggested visual sequence

Dashboard → Assignment detail → Source upload → Workflow output → Workfile Guardian → Verification item marked complete.

## Compliance boundaries to show or mention

“A workfile record supports review and organization. It does not prove that an appraisal conclusion or compliance requirement is correct. The appraiser remains responsible for verification and professional judgment.”

## Suggested closing CTA

“Create an assignment and turn your next AI-assisted task into a traceable workfile artifact.”
