# Revision Response Agent — Product Walkthrough Script

## Video purpose

Show how a residential appraiser turns a reviewer, lender, AMC, or client revision request into a professional draft, a support checklist, and a saved workfile artifact.

Suggested length: 90–120 seconds.

## Core promise

CoAppraiser helps the appraiser understand what a revision request is really asking and prepare a neutral, reviewable response without replacing professional judgment.

## Screen-by-screen walkthrough

### 1. Open the workspace

**Screen:** Dashboard → select an assignment → open **Revision Response Agent**.

**Voiceover:**

“When a revision request arrives, open the assignment and launch Revision Response Agent. The workflow keeps the request connected to the assignment workfile.”

### 2. Paste the request

**Screen:** Paste: “Please provide additional support for the GLA adjustment.”

**Screen:** Add a relevant report excerpt and rough appraiser notes.

**Voiceover:**

“Paste the request exactly as received. Add the report section or notes that provide context. CoAppraiser works from the material you provide; it does not pretend to have verified facts it has not seen.”

### 3. Generate the response package

**Screen:** Click **Generate response**.

**Show:** Issue Summary, What the Request Is Asking For, Recommended Action, Draft Response, Optional Report Language, Workfile Note, What to Verify, and Risk Flags.

**Voiceover:**

“The result separates the reviewer’s question from the recommended next step. It drafts professional language, identifies missing support, and flags what the appraiser should verify before using anything.”

### 4. Review and edit

**Screen:** Edit the Draft Response textarea.

**Voiceover:**

“The response is a draft, not a conclusion. Edit it to reflect the actual assignment record and your own analysis. CoAppraiser is designed to keep the appraiser in control.”

### 5. Save the workfile artifact

**Screen:** Click **Save edits**, then **Approve artifact**. Open the Workfile.

**Voiceover:**

“Save the response and approve it only after review. The original AI output, your edited version, the action history, and verification items remain connected to the assignment.”

## Benefits to emphasize

- Faster first draft for recurring revision requests
- More neutral and professional response language
- Clearer list of evidence the appraiser still needs to verify
- Traceable workfile record instead of an untracked chat response

## Compliance boundaries to show or mention

“CoAppraiser does not determine value, make final adjustment decisions, complete an appraisal, or guarantee USPAP, UAD, GSE, lender, AMC, or client acceptance.”

## Suggested closing CTA

“Create a free CoAppraiser account and start with your next revision request.”
