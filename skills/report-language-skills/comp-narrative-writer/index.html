Comp Narrative Writer

A practical AI skill for appraisers who need to write concise comparable sale narratives from verified notes. It helps draft and organize language; it does not provide a final opinion of value.

Skill preview

Paste verified assignment context, rough notes, or report text. Review every output before using it.

What it does

This skill guides an AI assistant through a narrow real estate appraisal workflow: write concise comparable sale narratives from verified notes. It asks for context, separates facts from assumptions, and returns practical draft language plus a verification checklist.

Best for

Residential appraisers, review appraisers, trainees, and small appraisal offices that want consistent AI skills for appraisers without adopting new appraisal software.

Inputs

  • Reviewer comment, rough notes, report text, MLS CSV, public record text, or comp notes as applicable.
  • Assignment context and relevant report section.
  • Appraiser-provided facts and intended scope of work.

Outputs

  • Draft response, report language, QA punch list, feature summary, or workfile note.
  • Evidence and support checklist.
  • Items to verify before delivery.

Example prompts

  • Use this skill to organize the following notes into concise appraisal report language.
  • Review this text for unsupported statements, contradictions, and likely revision triggers.
  • Draft a professional response based only on the verified facts below.

What to verify

  • Subject, comparable, and market facts match the report and workfile.
  • No unsupported conclusion, value opinion, or compliance claim was introduced.
  • All citations, dates, adjustments, and property characteristics are correct.
  • The final language fits your scope of work and applicable requirements.
